# Документация Qt 6.10

Справочная карта модулей Qt 6.10 для быстрого поиска документации и примеров кода. Каждый модуль содержит описание, ключевые классы, примеры и информацию о подключении через CMake.

Модули, которые определяют основу Qt на всех платформах:

| Модуль | Описание | Ссылка |

## Структура документации

Каждый модуль содержит:

- **Описание** — назначение и основные возможности модуля
- **Обзор** — ссылки на официальную документацию
- **Ключевые концепции** — важные темы и паттерны использования
- **Ключевые классы** — таблица с наиболее важными C++ классами и ссылками на документацию
  - ⚠️ **Важно:** Таблица содержит только наиболее часто используемые классы
  - 📋 **Полный список всех классов модуля** доступен по ссылке `-module.html` (например, [qtcore-module.html](https://doc.qt.io/qt-6/qtcore-module.html))
  - Полные списки содержат описания и ссылки на ВСЕ классы модуля и являются наиболее актуальным источником
- **Примеры** — ссылки на примеры использования
- **CMake конфигурация** — как подключить модуль к проекту
- **Связанные модули** — перекрестные ссылки на другие модули

## Использование в проекте

Для использования модуля Qt в проекте:

1. Добавьте модуль в `CMakeLists.txt`:
   ```cmake
   find_package(Qt6 REQUIRED COMPONENTS ModuleName)
   target_link_libraries(my_target PRIVATE Qt6::ModuleName)
   ```

2. Включите необходимые заголовки в исходный код:
   ```cpp
   #include <QModuleClass>
   ```

3. Обратитесь к документации модуля для примеров использования
