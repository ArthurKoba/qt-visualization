# Стандарты проекта

## Обзор
Этот документ определяет стандарты кодирования и практики разработки для этого проекта.

## Общие правила для всех агентов

### Коммуникация и документирование
- Не расписывай "Преимущества использования" подходов, способов, методов и т.д. без явной просьбы указать или расписать их. В большинстве случаев это абсолютно неинформативные данные.
- Для комментариев, документации, Markdown файлов обязательно используй русский язык.
- Будь лаконичен и точен в описаниях.

### Работа с документацией и примерами
- При добавлении нового функционала, реализации алгоритмов и в целом работе с Qt компонентами обязательно загружай документацию и примеры ИЗ ИНТЕРНЕТА.
- Используй версии Qt 6.9.2 или Qt 6.10 при поиске примеров и документации.
- Для Qt-специфичных задач загружай соответствующие стандарты из папки `qt/` через ссылки `#[[file:...]]`.

### Архитектура и проектирование
- **Обязательное правило:** При добавлении нового функционала или модуля ВСЕГДА обновляй [Карту проекта](.kiro/steering/project-map.md) с описанием новых компонентов, их назначения и взаимодействия с существующей системой.
- Используй [Карту проекта](.kiro/steering/project-map.md) для понимания архитектуры при решении комплексных задач.

## Иерархия стандартов

Стандарты организованы иерархически для постепенного наполнения контекста:

### Уровень 1: Основные стандарты (всегда загружаются)
- **project-standards.md** — этот файл, общие правила проекта

### Уровень 2: Специализированные стандарты (загружаются по необходимости)
- **qt/** — папка с Qt-специфичными стандартами
  - Загружаются через явные ссылки `#[[file:.kiro/steering/qt/...]]` в зависимости от контекста задачи
  - Примеры: `#[[file:.kiro/steering/qt/qt-network.md]]`, `#[[file:.kiro/steering/qt/qt-multimedia.md]]`, `#[[file:.kiro/steering/qt/qt-sql.md]]`

### Уровень 3: Архитектурные документы
- **project-map.md** — архитектурная карта проекта (загружается при работе с архитектурой)
- **arch-coding-standards.md** — архитектурные стандарты кодирования
- **cpp-coding-standards.md** — C++ стандарты кодирования

## Правила загрузки контекста

**Пример 1: Реализация сетевого компонента**
1. Загружается: `project-standards.md` (автоматически)
2. Загружается: `project-map.md` (для понимания архитектуры)
3. Загружается: `#[[file:.kiro/steering/qt/qt-network.md]]` (через явную ссылку)
4. Загружается: `cpp-coding-standards.md` (для стиля кода)

**Пример 2: Работа с аудио**
1. Загружается: `project-standards.md` (автоматически)
2. Загружается: `#[[file:.kiro/steering/qt/qt-multimedia.md]]` (через явную ссылку)
3. Загружается: `project-map.md` (если нужна архитектура)
